HOSTING THE KRAMER LAB WEBSITE ON GITHUB PAGES
================================================

INITIAL SETUP (one time only)
------------------------------

1. Go to github.com and sign in (or create a free account).

2. Click the "+" icon in the top right corner and select "New repository".

3. Name it: kramer-lab-website
   Set visibility to: Public
   Leave everything else unchecked. Click "Create repository".

4. Copy the repository URL shown on the next page. It will look like:
   https://github.com/YOUR-USERNAME/kramer-lab-website.git

5. Open a terminal in the kramer-lab-website folder.
   In VS Code: go to Terminal > New Terminal.

6. Run these commands one at a time:

   git init
   git add .
   git commit -m "Initial site upload"
   git branch -M main
   git remote add origin https://github.com/YOUR-USERNAME/kramer-lab-website.git
   git push -u origin main

   (Replace YOUR-USERNAME with your actual GitHub username.)

7. On GitHub, go to your repository and click "Settings".
   In the left sidebar, click "Pages".
   Under "Branch", select "main" and folder "/ (root)", then click "Save".

8. Wait about 1 minute. Your site will be live at:
   https://YOUR-USERNAME.github.io/kramer-lab-website/


UPDATING THE WEBSITE
--------------------

Whenever you make changes to any files, run these three commands
in the terminal from the kramer-lab-website folder:

   git add .
   git commit -m "Brief description of what you changed"
   git push

Examples of commit messages:
   "Added Keira's photo and bio"
   "Updated news section"
   "Added new lab photo for 2026"

The site will update automatically within about 1 minute of pushing.


LINKING YOUR CUSTOM DOMAIN (kramerlab.net via GoDaddy)
-------------------------------------------------------

Do this after completing the initial setup above.

STEP 1 — Tell GitHub about your domain:

1. Go to your GitHub repository and click "Settings".
2. In the left sidebar, click "Pages".
3. Under "Custom domain", type: kramerlab.net
4. Click "Save".
   GitHub will add a file called CNAME to your repository automatically.

STEP 2 — Set up DNS records in GoDaddy:

1. Log in to GoDaddy and go to "My Products".
2. Next to kramerlab.net, click "DNS" or "Manage DNS".
3. You need to add four A records and one CNAME record.

   First, delete any existing A records pointing to GoDaddy's default
   servers (they will conflict).

   Add these four A records (for the root domain kramerlab.net):
   Type: A  |  Name: @  |  Value: 185.199.108.153  |  TTL: 600
   Type: A  |  Name: @  |  Value: 185.199.109.153  |  TTL: 600
   Type: A  |  Name: @  |  Value: 185.199.110.153  |  TTL: 600
   Type: A  |  Name: @  |  Value: 185.199.111.153  |  TTL: 600

   Add this CNAME record (so www.kramerlab.net also works):
   Type: CNAME  |  Name: www  |  Value: YOUR-USERNAME.github.io  |  TTL: 600

   (Replace YOUR-USERNAME with your actual GitHub username.)

4. Save your changes.

STEP 3 — Enable HTTPS:

1. DNS changes can take anywhere from a few minutes to 48 hours to
   propagate. Once they have, go back to GitHub Settings > Pages.
2. Check the box that says "Enforce HTTPS".
   This secures your site and is strongly recommended.

After everything is set up, your site will be accessible at:
   https://kramerlab.net
   https://www.kramerlab.net


NOTES
-----
- Always make sure you are in the kramer-lab-website folder when
  running git commands.
- The commit message (in quotes after -m) is just for your own
  reference — write whatever makes sense to you.
- You do not need to repeat the initial setup steps. After the
  first time, only the three "Updating" commands are needed.
